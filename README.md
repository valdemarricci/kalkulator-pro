# Kalkulator

Kalkulator w formie kreatora: zamiast liczyć od razu, odpowiadasz na kilka pytań (system cyfr, działania, liczby, wygląd wyniku), a wynik trafia do pliku PDF, CSV albo e-maila. Wyniku nie widać na ekranie. Projekt żartobliwy, pokazujący, jak wygląda bardzo niewygodne UX w nowoczesnym wydaniu.

## Funkcje

- ekran powitalny i kreator z paskiem postępu
- cyfry arabskie, rzymskie, dwójkowe i szesnastkowe, z krótką historią każdego systemu
- dowolna liczba kroków (do 10), działania wykonywane od lewej do prawej
- wybór czcionki, rozmiaru, pogrubienia i koloru wyniku (także własnego)
- captcha, regulamin do przewinięcia i ankieta na końcu
- 50% szans, że zamiast wyniku dostaniesz odesłanie do matematyka
- eksport: e-mail, PDF, CSV

## Uruchomienie

Pojedynczy plik, bez instalacji. Otwórz `index.html` w przeglądarce.

Pobieranie PDF i CSV działa po otwarciu pliku z dysku lub ze strony GitHub Pages.

## Uwagi

- ankieta na końcu nigdzie nie zapisuje odpowiedzi (brak serwera)
- do PDF używane są standardowe czcionki PDF, najbliższe wybranej
